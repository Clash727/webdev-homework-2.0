# Fonts
Barlow Condensed (Latin, 500/700/800) and available Noto Serif SC Unicode subsets. Both are licensed under SIL Open Font License; notices are retained alongside the files.
Font source: Google Fonts CSS / fonts.gstatic.com. Local files are referenced by web/css/fonts.css, with no external runtime requests.
The font download was interrupted by network errors. Only successful subsets are included. Chinese characters not present in those subsets fall back to local SimSun / Songti SC, then the platform serif font.
