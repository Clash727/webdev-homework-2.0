# 团队与成员资料管理

已接入现有管理员登录，在管理工作台提供团队资料入口。

- `/admin/team`：编辑团队名称、简介，维护团队资源链接，并进入四位成员的编辑页。
- `/admin/members/{id}/edit`：编辑成员姓名、角色与分工、简介、显示顺序及个人公开链接。
- 链接支持添加、修改、排序和勾选删除；空白新行忽略，未提交的已有链接保留。
- 保存成功后，公开团队页、成员页及项目页中的成员姓名同步显示；既有分工关联保持稳定。

资料与链接在同一事务中保存，任何校验失败均不落库。后台沿用现有认证和 CSRF 校验，拒绝修改团队标识、成员归属及分工关联键，并校验链接属于当前资料。公开链接仅接受 HTTP/HTTPS，输出经过转义。

## 数据库

运行 `php yii migrate`，新增迁移 `m261116_300001_create_project_team_link_table` 创建团队资源链接表。成员个人链接复用已有表。
