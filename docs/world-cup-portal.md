# 世界杯主题站与四人团队展示

已完成四个一级页面及统一导航：主页、团队成员、项目经历、世界杯专题。世界杯专题内含赛程与赛果、精彩进球、球迷讨论三个栏目，使用普通页面链接切换，支持直接访问与浏览器前进、后退。

| 入口 | 展示内容 |
| --- | --- |
| `/` | 2026 世界杯主题图形、最近更新的最多三条已发布赛果、专题入口、团队摘要 |
| `/team` | 四位占位成员、分工及成员详情入口；桌面四列，窄屏自然排列 |
| `/project` | 项目介绍、四人职责范围与已实现成果链接 |
| `/world-cup` | 复用原赛程控制器与数据；原 `/world-cup/matches` 仍可访问 |
| `/world-cup/highlights` | 原创封面卡片与 FIFA 官方观看链接，不托管视频或加载外部播放器 |
| `/world-cup/fans` | 仅展示已通过的球迷留言；留言表及原提交控制器可用后提供提交入口 |

首屏球场、足球与成员占位形象均由本地 CSS / SVG 绘制，无外部图片、字体或 CDN 运行依赖。姓名暂用成员一至四，不填充真实人员信息；分工范围与已实现成果分别呈现，不将后续安排当成已完成工作。

当前采用深蓝首屏、荧光绿主按钮及橙色点缀；成员卡片以球衣编号呈现占位身份。团队名称使用“我们的团队”，页面不使用旧项目品牌。

## 数据与初始化

```text
php yii migrate --interactive=0
php yii team-seed
```

新库初始化创建四位占位成员。`project_member.contribution_key` 使用 `member-1` 至 `member-4`，同一团队中唯一；该标识把成员与 `config/portfolio.php` 的分工展示关联起来，改名及排序不影响归属。原有成员可为空标识，不会被初始化命令覆盖。

已经运行过旧两人演示种子的本机，可以显式执行：

```text
php yii team-seed/complete-demo
```

该命令只接受未经维护的原始演示资料，保留已有成员 ID 与个人链接，并在一个事务中补齐四人。遇到实际编辑过的团队或成员会拒绝改动；重复运行保留四人资料。现有自定义团队不应通过删除或重置来升级。

首页只使用 `Fixture::findPublished()`，限定 2026 届次及完赛状态，按赛果更新时间排序；草稿不会进入首页。比赛时间显示北京时间。球迷讨论复用 `guest_message`，不新增另一套留言表、账号或审核流程；当前留言功能尚未合入，页面如实显示开放状态，不添加虚构评论。
