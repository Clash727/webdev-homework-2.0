# W09 第一版：多彩海报视觉

2026-11-16。按用户选定的 A 方向和提供的配色图实现，保留现有业务、路由和数据查询。

## 视觉

- 从参考图取色：深绿 #014E3E、薄荷青 #64FCDB、紫 #6400E9、黄绿 #B0EA03、橙红 #FE3D01、蓝 #334CFD、浅紫 #B089FE。
- 首页采用原创多层环带与巨大年份、宋体标题；赛果改为无外框的横排记录，专题入口错位排列。
- 团队成员以不同弧形轮廓和球衣编号呈现；项目分工、赛程、比赛详情、精彩进球、讨论页、登录和资料编辑使用统一色板与排版。
- 字体为本地 Barlow Condensed 与成功下载的 Noto Serif SC 子集。下载因网络错误中断，未包含的中文字形按 SimSun / Songti SC / serif 回退。页面运行不请求 Google 字体服务，字体许可保存在 web/fonts/。
- 环带缓慢摆动、标题入场、内容滚动显现和悬停反馈；减少动态效果偏好下关闭动画。滚动显现不依赖预先隐藏正文。
